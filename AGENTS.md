# Agent instructions — OakNexis/.github

## What this repo is

Default community health files for the OakNexis GitHub organization. Files in this repository apply automatically to all OakNexis repositories that do not define their own versions.

## Files

| File | Purpose |
|---|---|
| `PULL_REQUEST_TEMPLATE.md` | Default PR template for all repositories |
| `.github/ISSUE_TEMPLATE/bug_report.md` | Bug report template |
| `.github/ISSUE_TEMPLATE/feature_request.md` | Feature request template |
| `CONTRIBUTING.md` | Contribution guidelines (branches, commits, PRs, review) |
| `profile/README.md` | Public organization profile shown on github.com/OakNexis |

## Rules

- Never change the tone or structure of templates without explicit instruction — they apply org-wide
- Keep templates language-neutral (English only) — they are used across all repositories
- Do not add required fields to issue or PR templates — keep them lightweight
- Commit messages follow the format: `type: short description` (no task prefix needed in this repo)
- Always keep `profile/README.md` consistent with the organization's public profile (bio, website, contact)
